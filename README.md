# UTD-EPICS workshop

RAG (Retrieval-Augmented Generation) combines information retrieval with LLM generation. 
The application first retrieves relevant information from a knowledge source such as a vector database, then provides that information to the LLM as context for generating the response. 
The RAG system workflow is commonly comprised of three main components:
* Embedding model: A pre-trained language model that converts input text into embeddings (vector representations that capture semantic meaning).
* Vector database: A storage system for knowledge and its corresponding embedding vectors.
* Chatbot: A language model that generates responses based on retrieved knowledge.
